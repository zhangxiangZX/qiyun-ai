## 建议客户首次使用路径（操作手册）

1. 打开 `http://localhost:3010/login` → 点击「申请试用」
2. 填写企业名称、联系人、工作邮箱 → 提交
3. 等待管理员审核开通（开发环境可直接用已有账号登录）
4. 登录后按顺序：**知识库上传资料 → 创建/配置机器人 → 站点嵌入 → 官网验证 Widget → 查看会话/线索/报表**
