## 3. 本轮修复

1. 修复数据中心占位页仍使用旧日期工具栏参数导致的编译失败。
2. 修复快速录入两个重置按钮的点击事件类型错误。
3. 补齐角色首页趋势映射缺少的 `TrendRange` 类型。
4. 登录表单增加原生 POST 兜底，避免页面未完成加载时把账号密码放入 URL。
5. 忘记密码改为原生链接，确保弱网或 JavaScript 未接管时仍可跳转。
6. 提升知识库 KPI 绿色趋势文字对比度，达到 WCAG 要求。
7. 更新 AI 助手、系统状态和忘记密码自动化断言，使其与当前 UI 语义一致。
8. 点击巡检器增加自动重定向重试，修复验收页、报表页和超级管理员页的误报。
9. 视觉回归固定到明确的老板首页；实时经营列表仅检查稳定首屏，内容页继续检查整页。
