# 42 · 企云图 AI 前端全页面功能重测清单

> 生成日期：2026-07-20
> 依据：实际 `apps/console/src/app/**/page.tsx`、`apps/console/src/lib/navigation.ts`、V1 冻结结构。
> 目标：逐页验证功能、跳转、状态、权限与视觉一致性，并找出“页面能打开但业务不顺”的问题。
> 状态：`未测` / `通过` / `失败` / `阻塞` / `不适用`。

---

## 0. 本轮结论先行

- 实际路由数量远高于 V1 侧栏页面数量，包含正式 V1、公开入口、平台超管、重定向、内部验收页和 V2 隐藏页。
- 本轮先验收 **V1 核心闭环**，再验收隐藏页；不得因为隐藏原型页可打开就判定 V1 完成。
- 所有页面必须标明数据模式：`真实接口` / `真实接口+演示降级` / `纯演示`。纯演示页不得在正式角色侧栏中制造“已上线”错觉。
- 体验验收不只检查按钮可点，还必须检查：用户是否知道当前处于哪一步、完成后去哪一步、失败后如何恢复。

核心闭环：

```text
登录 → 配置企业和成员 → 上传知识库 → 创建 AI 助手
→ 配置 Widget / AI 选型页 / 销售链接
→ 客户咨询或提交需求 → 生成询盘 → 分配销售
→ 创建跟进 → 创建报价 → 客户查看 → 成交/丢单 → 数据中心
```

## 1. 每个页面都必须执行的通用检查

### 1.1 功能

- [ ] 页面直接访问不白屏、不无限加载、不出现 hydration/runtime error。
- [ ] 主按钮、次按钮、文字链接、表格行、卡片入口全部点击一次。
- [ ] 所有搜索、Tab、筛选、排序、分页可组合使用，清空条件后可恢复完整列表。
- [ ] 表单必填、格式、长度、重复值、前后空格和服务端错误均有明确提示。
- [ ] 创建、编辑、删除、启停、发布、复制、下载、导出均有成功或失败反馈。
- [ ] 删除、作废、成交、拒绝等不可逆操作有二次确认。
- [ ] 操作成功后列表、统计卡、详情状态同步刷新，不需要手动刷新浏览器。
- [ ] URL 可刷新、可后退、可复制打开；动态 ID 不存在时有友好错误页。
- [ ] Loading、Empty、Error、无权限、429、网络断开均有可恢复入口。
- [ ] 演示数据与真实数据有清楚标识，不允许混在同一统计口径中。

### 1.2 视觉与交互

- [ ] 页面标题统一 24px 左右，模块标题统一 16px 左右，正文和表格统一 14px 左右，辅助文字统一 12px 左右。
- [ ] 页面左右边距、标题区高度、卡片内边距、表格行高、按钮高度保持一致。
- [ ] 同级页面使用同一种页头、面包屑、筛选区、卡片圆角、边框和阴影。
- [ ] 主按钮每页原则上不超过一个，危险按钮不使用主蓝色。
- [ ] 空态必须告诉用户“为什么为空”和“下一步做什么”。
- [ ] 禁用态说明原因，不能只把按钮变灰。
- [ ] 1366×768 不横向溢出；1024 宽可完成主要操作；公开客户页验证 375×812。
- [ ] 键盘 Tab 可到达主要操作；弹窗打开后焦点进入弹窗，关闭后回到触发按钮。
- [ ] 所有图标有一致尺寸，纯图标按钮有可访问名称或提示。

### 1.3 业务连续性

- [ ] 页面说明清楚当前任务属于闭环哪一步。
- [ ] 完成当前操作后提供唯一明确的下一步。
- [ ] 从上一页进入、保存、返回后，上下文和筛选条件不丢失。
- [ ] 同一对象在列表、详情、工作台和报表中的名称、状态、负责人一致。

## 12. 必须按顺序执行的端到端流程

### Flow-01 新企业启用

- [ ] 申请试用 → 超管审核 → 复制邀请链接 → owner 接受邀请 → 首次登录。
- [ ] 填企业资料 → 邀请管理员/销售 → 切换角色验证权限。

### Flow-02 知识库到真实问答

- [ ] 新建知识库 → 上传库滋玛 PDF → 解析/清洗/索引 ready。
- [ ] 创建助手 → 关联知识库 → 配置行为 → AI 测试真实命中并显示引用。
- [ ] 删除/替换文档后旧答案不再命中。

### Flow-03 官网 Widget 获客

- [ ] 添加站点 → 复制安装代码 → 域名检测 → 打开 Widget。
- [ ] 产品问答 → 高意向识别 → 引导留资 → 会话持久化 → 自动生成询盘和首次跟进。

### Flow-04 AI 选型页获客

- [ ] 新建 → 配置问题/产品 → 手机预览 → 发布 → 公开页提交。
- [ ] 上传图纸 → 留资 → 后台提交记录 → 自动询盘 → 分配销售。

### Flow-05 销售链接获客

- [ ] 创建链接 → 生成二维码 → 手机扫码 → 留资。
- [ ] 来源准确记录为链接/销售/渠道 → 生成询盘 → 统计访问和转化。

### Flow-06 销售成交

- [ ] 待分配询盘 → 分配销售 → 首次跟进 → 补充资料。
- [ ] 转报价 → 选择模板 → 生成 PDF → 客户查看 → 确认/拒绝。
- [ ] 成交/丢单 → 工作台、漏斗、渠道和销售分析同步更新。

### Flow-07 异常恢复

- [ ] API 断开、Redis/Qdrant/MinIO 不可用时页面有明确降级。
- [ ] 上传失败、AI 超时、SSE 中断、邮件失败、邀请过期均可恢复。
- [ ] 重试不会重复创建询盘、任务、报价或成员。

## 13. 视觉统一专项

### 页面框架

- [ ] 控制台统一内容最大宽度和左右边距，不允许同级页面忽宽忽窄。
- [ ] 页头统一为：面包屑/标题/说明/主操作；避免每页自创页头。
- [ ] 筛选栏统一顺序：Tab → 搜索 → 筛选 → 重置 → 批量操作。
- [ ] 详情页统一为：对象摘要 → 状态/关键操作 → Tab/内容 → 时间线。

### 字体与密度

- [ ] 禁止页面局部使用大量 inline font-size 形成另一套字号。
- [ ] 表格、表单、卡片和统计卡采用统一密度。
- [ ] 中文数字、金额、百分比对齐，长公司名和型号有省略及悬浮查看。

### 状态与反馈

- [ ] 统一使用成功、警告、错误、信息、禁用五种语义色。
- [ ] 状态徽标文案统一，询盘和报价不得在不同页面使用不同中文名称。
- [ ] Toast 只反馈短结果；复杂错误使用页面 Alert，并提供重试/返回。

### 响应式

- [ ] 1920、1440、1366 三档无明显布局跳变。
- [ ] 1024 下侧栏可收起、表格提供合理横向容器或卡片降级。
- [ ] 公开选型页、客户报价页、邀请页在 375×812 完整可操作。
