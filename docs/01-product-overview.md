# 01 产品说明书｜Enterprise AI Platform

## 1. 产品名称
**智企 AI（暂定）**  
英文：Enterprise AI Platform

## 2. 一句话定位
为中小企业提供“可嵌入官网的 AI 客服 + 企业知识库 + 线索收集 + 数据分析”的一站式 SaaS / 私有化部署平台。

## 3. 目标客户
- 制造业、设备、外贸、服务业等拥有官网和产品资料的中小企业
- 有售前咨询量、产品资料分散、客服重复答复问题的企业
- 数字化服务商、网站建设公司、软件外包团队

## 4. 客户痛点
1. 官网访客得不到即时答复，线索流失。
2. 产品手册、FAQ、报价资料分散，客服新人熟悉成本高。
3. 企业不知道访客问了什么、哪些问题无法回答。
4. 同类 AI 产品太复杂，部署与配置门槛高。

## 5. V1 核心价值
- 30 分钟完成“上传资料 → 配置机器人 → 嵌入官网”。
- AI 仅基于企业知识库回答，并展示引用来源。
- 无法回答时自动收集姓名、电话、邮箱和问题，转为线索。
- 管理者可看到会话量、线索量、未命中问题和知识库效果。

## 6. 商业模式（建议）
| 版本 | 目标客户 | 建议价格 | 核心限制 |
|---|---|---:|---|
| 试用版 | 意向客户 | 7 天免费 | 1 个机器人、有限消息 |
| 标准版 | 小微企业 | 699–999 元/月 | 1 站点、基础知识库 |
| 专业版 | 成长企业 | 1999–2999 元/月 | 多机器人、分析与品牌定制 |
| 私有化 | 有数据合规需求企业 | 2–10 万部署费 + 年维护 | 专属部署、可选本地模型 |

## 7. V1 范围
### 必做
- 注册、登录、工作区、成员与角色
- 知识库：文件上传、文本切分、向量化、检索、状态管理
- 机器人：系统提示词、模型、欢迎语、线索收集开关
- Web Chat Widget：脚本嵌入、流式回复、来源引用、表单留资
- 控制台：会话、线索、基础数据看板
- API Key / 站点域名白名单
- Docker Compose 部署

### 明确不做
- 微信/企业微信/钉钉/飞书渠道
- CRM、订单、合同
- 工作流编排、MCP 市场
- 在线支付、发票、复杂计费
- OCR、表格结构化、图片理解（可在 V1.1 追加）

## 8. 成功指标
- 首次创建机器人完成率 ≥ 70%
- 上传知识库后 10 分钟内可用率 ≥ 95%
- 首次有效回答率 ≥ 60%
- 留资转化率可监测，且可导出
- 单个客户从注册到嵌入网站 ≤ 30 分钟
