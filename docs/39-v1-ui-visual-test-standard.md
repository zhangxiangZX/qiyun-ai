# 39 · 企云图 AI V1 UI 视觉与交互全量测试规范

> 状态：冻结为 Cursor / Codex 测试规则配套文档  
> 规则入口：`.cursor/rules/ui-visual-test.mdc`  
> 页面清单：`docs/40-v1-ui-page-test-checklist.md`  
> 设计 Token：`docs/07-design-system.md`、`packages/ui/src/styles/theme.css`

## 1. 总原则

**测试对象：** 所有页面 + 所有弹窗 + 所有抽屉 + 所有表单 + 所有按钮 + 所有状态。

**目标：** 设计图 ≈ 实际页面（接近商业 SaaS，而非 Demo）。

**执行顺序（强制）：**

1. 维护并确认《V1 页面测试清单》（`docs/40`）
2. 按清单逐页人工/半自动验收
3. Playwright + Screenshot Diff 自动化
4. 输出《UI 测试报告》

## 2. 页面结构测试（每页必查）

每个页面生成检查清单，至少包含：

- [ ] 页面是否正常加载
- [ ] 顶部导航是否正确
- [ ] 左侧菜单是否正确
- [ ] 页面标题是否正确
- [ ] 面包屑是否正确
- [ ] 内容区域宽度是否正确（无异常左右大留白、无横向滚动）
- [ ] 卡片布局是否正确
- [ ] 表格布局是否正确
- [ ] 底部留白是否正确

## 3. 整体布局

### 3.1 页面宽度

| 视口 | 用途 |
|------|------|
| 1920×1080 | 桌面主测 |
| 1440×900 | 桌面主测 |
| 1366×768 | 桌面主测 |
| 1024 / 768 | 窄屏 |
| 375×812 | 仅 AI 选型独立页（手机） |

检查：横向滚动、内容截断、卡片变形。

### 3.2 左侧菜单

检查：Logo 位置、菜单宽度、间距、图标大小、文字大小、选中态、hover、展开收起动画。

常见错误：文字挤压、图标偏移、选中背景高度不一致、同级图标尺寸不统一。

## 4. 字体

字体栈（与 `theme.css` 一致）：

- 中文：`PingFang SC`、`Microsoft YaHei`
- 英文：Inter（`--font-inter`）

字号参考：

| 层级 | 约值 | weight |
|------|------|--------|
| 页面标题 | 24px | 600 |
| 模块标题 | 16px | 500 |
| 正文 | 14px | 400 |
| 辅助文字 | 12px | 400 |

检查：字体统一、无意外系统默认字体墙、无乱码、数字字重一致。

> 注：`docs/07` 中 H1 为 28–32；实现以 theme + 实际页面 token 为准，验收时「同级一致」优先于绝对像素。

## 5. 颜色

检查品牌主色在按钮、标签、高亮、链接上的统一；以及：

主按钮 / hover / disabled / 错误 / 成功 / 警告。

禁止业务页硬编码野色；语义色 success / warning / danger / info 一致。

## 6. 间距（高优先级）

- 页面：顶距、左右 padding、模块间距
- 卡片：圆角、阴影、内 padding、标题距、内容距
- 表格：列间距、行高、文字垂直居中、操作按钮间距

对齐 `docs/07`：4px 网格；卡片 padding 16/24；圆角控件 8 / 卡片 12 / 弹窗 16。

## 7. 图片素材

扫描目录：`/assets`、`/images`、`/static`、`public/`、引用的 CDN 路径。

1. **存在性**：`src` / `background-image` 指向的文件必须存在  
2. **尺寸**：头像约 40×40、Logo 约 120×40；禁止拉伸变形模糊  
3. **质量**：无明显锯齿、过度压缩  
4. **透明底**：AI 机器人等图标应为 PNG 透明，禁止白底方块

## 8. 图标

全站 lucide（或项目统一套）；同场景尺寸/颜色/线宽/居中一致。  
侧栏错误示例：首页 20px、客户 16px、报价 24px。

## 9. 响应式

后台以 PC 为主，仍须覆盖 §3.1 视口。  
检查：错乱、表格可横滚、弹窗不超出屏幕。

## 10. 按钮级测试

扫描：`button`、`a`、icon-button、dropdown、menu、tab、switch、checkbox、radio、input。

对每一项：点击响应、跳转正确、无权限隐藏/禁用、错误提示。

## 11. 弹窗 / 抽屉

打开 → UI（标题、关闭、宽高、按钮位、遮罩）→ 操作（取消不变 / 确认生效）。

## 12. 表单

placeholder、default / focus / 输入 / 错误 / 禁用；校验文案正确（如手机号）。

## 13. 页面状态

每页必须可验收：

| 状态 | 期望 |
|------|------|
| Loading | 骨架屏或明确 loading |
| Empty | 文案 + 引导 CTA（如「暂无询盘 / 立即创建」） |
| Error | 「加载失败 / 重新加载」 |
| 无权限 | 「暂无权限」或隐藏入口 |

## 14. 交互动画

页面切换、下拉、弹窗、Hover、Loading；按钮 hover 变色、提交 loading。  
动画用于层级，不做噪音炫技。

## 15. 截图自动比对

推荐：Playwright + Screenshot Diff。

流程：打开页面 → 截图 → 与设计稿/基线对比 → 计算差异（位置、字体、图片、颜色）。

基线目录建议：`tests/visual/baselines/`（落地时再建，勿与功能 E2E 混目录）。

## 16. 报告格式（强制）

执行角色提示词：

```text
你现在作为高级 UI 测试工程师。
对企云图 AI V1 所有清单内页面进行视觉验收。
必须逐页检查：布局、字体、颜色、间距、图片、图标、表格、卡片、弹窗、按钮、输入框、下拉、状态页、响应式、截图对比。
同时扫描所有可点击元素。
按 docs/40 勾选，输出 UI 测试报告。
```

报告条目：

```text
页面名称：
问题位置：
截图：
问题等级：P0 / P1 / P2
修改建议：
```

| 等级 | 含义 |
|------|------|
| P0 | 阻断客户试用（错乱、截断、核心不可用） |
| P1 | 明显不符设计 / 交互缺陷 |
| P2 | 微调（间距 2–4px、文案润色等） |
