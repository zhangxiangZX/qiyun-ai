# 企云 AI V1 使用流程说明

最后更新：2026-07-11

## 文档用途

本文档面向 **客户培训、销售培训、管理员 onboarding**，也可作为 Cursor / Codex 产品上下文参考。

- 验收边界：`docs/28-v1-acceptance-matrix.md`
- 页面清单：`docs/29-v1-final-page-checklist.md`
- V2 / 超范围能力：`docs/BACKLOG.md`（不计入 V1 交付承诺）

---

## 一、系统角色说明

企云 AI V1 主要有 3 类角色：

| 角色 | 职责 |
|------|------|
| **老板** | 看结果、看数据、看销售是否跟进 |
| **管理员** | 配置系统、上传资料、创建入口、管理成员 |
| **销售** | 发链接、录入客户、跟进询盘、创建报价 |

**一句话：老板看经营，管理员配系统，销售跑客户。**

---

## 二、整体业务流程

企云 AI 的核心流程是：

```text
客户来源
  ↓
销售链接 / AI 选型页 / 官网 Widget / 快速录入
  ↓
生成询盘
  ↓
AI 整理客户需求
  ↓
销售跟进客户
  ↓
创建报价
  ↓
发送报价
  ↓
报价后跟进
  ↓
成交 / 丢单
  ↓
老板查看数据
```

## 三、管理员首次配置流程

管理员是系统上线前最重要的人。第一步不是让销售直接用，而是先把企业基础资料和 AI 能力配置好。

### 1. 登录系统

```text
打开企云 AI 登录页
  ↓
输入账号和密码
  ↓
首次登录修改密码
  ↓
进入管理员首页
```

控制台入口：`/login` → `/dashboard/admin`

### 2. 完善企业资料

**入口：**

```text
系统设置
  ↓
企业资料
  ↓
企业资料编辑
```

控制台入口：**系统设置 → 企业资料**（`/dashboard/team/profile`）

**需要填写：**

- 企业名称、企业简称、所属行业、企业规模
- 官网地址、联系电话、企业邮箱
- 所在地区、详细地址、企业简介
- 主营产品、服务区域、默认联系提示语

**需要上传：**

- 企业 Logo、营业执照、产品目录、认证资质

**作用：**

- 用于 AI 选型页展示
- 用于报价单展示
- 用于官网 Widget 展示
- 用于客户报价页展示

### 3. 邀请团队成员

**入口：**

```text
系统设置
  ↓
团队成员
  ↓
邀请成员 / 编辑成员
```

控制台入口：**企业与账号 → 团队成员 / 邀请成员**（`/dashboard/team`、`/dashboard/team/invite`）

**添加成员时填写：**

- 姓名、手机号、邮箱、所属部门、角色、数据权限

**角色建议：**

| 角色 | 权限范围 |
|------|----------|
| 老板 | 看全部数据 |
| 管理员 | 配置系统和成员 |
| 销售 | 只看自己的询盘和报价 |

**邀请后：**

```text
成员收到账号
  ↓
首次登录修改密码
  ↓
进入对应角色首页
```

### 4. 上传知识库资料

**入口：**

```text
AI 能力中心
  ↓
知识库
  ↓
知识库上传
```

控制台入口：**AI 能力中心 → 知识库**（`/dashboard/knowledge-bases`）

**上传资料类型：**

- 产品手册、产品参数表、选型指南、公司介绍
- FAQ 常见问题、报价说明、售后政策
- 成功案例、安装维护手册

**上传后系统流程：**

```text
上传文件
  ↓
AI 自动解析
  ↓
生成知识片段
  ↓
标记解析成功 / 失败
  ↓
绑定给 AI 助手使用
```

**注意：**

- 知识库必须按企业隔离
- 每个企业只能使用自己的知识库
- AI 不能读取其他企业资料

### 5. 配置 AI 助手

**入口：**

```text
AI 能力中心
  ↓
助手列表
  ↓
助手配置
```

控制台入口：**AI 能力中心 → 助手列表 / 助手配置**（`/dashboard/bots`、`/dashboard/bots/config`）

**配置内容：**

- 助手名称、助手头像、助手简介、欢迎语、语言、可见范围
- 绑定知识库、推荐问题、对话流程、表单设置、渠道设置

**配置完成后：**

```text
保存配置
  ↓
AI 对话测试
  ↓
确认回答准确
  ↓
发布助手
```

控制台入口：**AI 能力中心 → AI 对话测试**（`/dashboard/conversations/test`）

**AI 助手用途：**

- 官网 Widget 问答
- AI 选型页问答
- 客户需求整理
- 销售录入辅助

### 6. 创建 AI 选型页

**入口：**

```text
获客入口
  ↓
AI 选型页
  ↓
新建 AI 选型页
```

控制台入口：**获客入口 → AI 选型页**（`/dashboard/bots/landing`）

**配置内容：**

- 页面名称、页面链接、适用行业、适用产品、页面风格
- 绑定 AI 助手、表单字段、提交后动作、负责人、渠道来源

**客户看到的页面支持：**

- 产品选择、AI 问答
- 填写尺寸 / 数量 / 使用环境
- 上传图纸、填写联系方式、提交报价需求

**发布后系统生成：**

- AI 选型页链接、AI 选型页二维码

**可用于：**

- 微信转发、抖音主页链接、小红书私信
- 展会二维码、产品资料二维码、销售朋友圈

### 7. 配置官网 Widget

**入口：**

```text
获客入口
  ↓
官网 Widget
  ↓
添加站点 / 绑定域名
```

控制台入口：**获客入口 → 官网 Widget**（`/dashboard/sites`）

**配置流程：**

```text
填写站点名称
  ↓
绑定官网域名
  ↓
配置 Widget 样式
  ↓
设置欢迎语
  ↓
绑定 AI 助手
  ↓
复制安装代码
  ↓
安装到客户官网
  ↓
检测安装状态
  ↓
发布上线
```

**Widget 功能：**

- 官网右下角 AI 咨询入口
- 回答产品问题
- 引导客户进入 AI 选型页
- 收集联系方式、生成询盘

### 8. 创建销售链接 / 二维码

**入口：**

```text
获客入口
  ↓
销售链接
  ↓
创建销售链接
```

控制台入口：**获客入口 → 销售链接**（`/dashboard/channels/links`）

**配置内容：**

- 链接名称、所属销售、绑定 AI 选型页、渠道来源
- 是否自动分配、是否需要客户留资、是否启用

**生成后：**

- 销售专属链接、销售专属二维码

**适用场景：**

- 微信聊天发给客户、老客户推荐新客户
- 展会扫码、产品资料扫码
- 电话沟通后补充资料、抖音 / 小红书私信

## 四、销售日常使用流程

销售不要接触复杂配置。销售每天只需要做 4 件事：**发链接、看询盘、跟进客户、创建报价**。

### 1. 销售登录

```text
打开登录页
  ↓
输入账号密码
  ↓
进入销售首页
```

控制台入口：`/login` → `/dashboard/sales-rep`

**销售首页看到：**

- 我的新询盘、今天要跟进、逾期未跟进
- 待报价、报价后未回复、高意向客户
- 我的销售链接、快速录入入口

### 2. 发销售链接给客户

**入口：**

```text
获客入口
  ↓
销售链接
```

或从 **销售首页 → 我的销售链接** 进入。

**销售操作：**

- 复制链接，或下载二维码
- 发送给微信客户 / 电话客户 / 老客户 / 展会客户

**销售话术示例：**

> 您好，您可以点这个链接，把产品需求、尺寸、数量和图纸先提交一下。系统会自动整理成报价需求，我这边可以更快给您出方案。

**客户提交后：**

```text
客户填写需求
  ↓
上传图纸
  ↓
留下联系方式
  ↓
系统生成询盘
  ↓
自动归属给该销售
```

### 3. 电话 / 微信客户快速录入

**入口：**

```text
客户机会
  ↓
快速录入
```

控制台入口：**客户机会 → 快速录入**（`/dashboard/quick-entry`）

**适合场景：**

- 客户打电话咨询、微信聊天咨询
- 老客户介绍客户、销售展会拿到名片
- 客户没有主动填表

**销售可以粘贴：**

> 客户要 20 台户外机柜，尺寸 800×600×2000，放沿海，要 IP65，老客户王总介绍，月底前要报价。

**AI 自动整理：**

| 字段 | 示例 |
|------|------|
| 产品 | 户外机柜 |
| 数量 | 20 台 |
| 尺寸 | 800×600×2000 |
| 使用环境 | 沿海 |
| 防护等级 | IP65 |
| 来源 | 老客户推荐 |
| 推荐人 | 王总 |
| 意向等级 | 高 |
| 缺失信息 | 图纸、交期 |
| 下一步建议 | 联系客户补充图纸和交期 |

**销售确认后：**

```text
保存为询盘
  ↓
进入询盘中心
```

### 4. 查看询盘中心

**入口：**

```text
客户机会
  ↓
询盘中心
```

控制台入口：**客户机会 → 询盘中心**（`/dashboard/inquiries`）

**询盘来源包括：**

- AI 选型页、销售链接、官网 Widget、快速录入
- 电话、微信、老客户推荐、展会二维码、产品资料二维码

**销售重点看：**

- 新询盘、高意向客户、待补充资料
- 待报价客户、最近未跟进客户

**询盘状态：**

`新询盘` → `已分配` → `跟进中` → `待补充` → `待报价` → `已报价` → `已成交` / `已丢单` / `无效`

### 5. 查看询盘详情

**入口：**

```text
询盘中心
  ↓
点击某条询盘
  ↓
询盘详情
```

**销售需要看：**

- 客户是谁、联系方式、客户从哪里来
- 要什么产品、需求是否完整、有没有图纸
- 还缺什么资料、AI 建议下一步怎么做

**常用操作：**

- 添加跟进记录、修改意向等级、补充客户资料
- 上传附件、修改负责人、转报价
- 标记无效、标记丢单

### 6. 添加跟进记录

**入口：**

```text
询盘详情
  ↓
添加跟进记录
```

**填写：**

- 跟进方式：电话 / 微信 / 邮件 / 面谈
- 跟进时间、沟通纪要、客户反馈
- 下次跟进时间、当前意向等级
- 是否同步创建跟进任务

**提交后：**

```text
跟进记录保存
  ↓
询盘状态更新
  ↓
如果设置下次跟进时间，自动创建跟进任务
```

### 7. 创建跟进任务

**入口：**

```text
询盘详情 → 创建跟进任务
```

或：

```text
销售跟进 → 跟进任务 → 新建跟进任务
```

控制台入口：**销售跟进 → 跟进任务**（`/dashboard/tasks`）

**任务类型：**

- 电话跟进、微信跟进、图纸确认、报价确认
- 交期确认、报价后追踪、客户回访

**任务状态：**

`待处理` → `进行中` → `已完成` / `已逾期` / `已取消`

**销售每天应该优先处理：**

- 今日待跟进、逾期未跟进
- 报价后未回复、高意向客户

### 8. 询盘转报价

**入口：**

```text
询盘详情
  ↓
转报价 / 生成报价
```

系统弹出确认：**确认将该询盘转为报价？**

**确认后：**

- 自动带入客户信息、产品需求、附件
- 进入新建报价页面

### 9. 新建报价

**入口：**

```text
报价管理 → 新建报价
```

或：**询盘详情 → 生成报价**

控制台入口：**报价管理**（`/dashboard/quotes`）

**报价内容：**

- 客户信息、报价信息、币种与税率
- 产品明细、费用项、交付与付款条款、备注说明、附件

**销售可以选择报价模板：**

- 标准设备报价模板
- 外贸英文报价模板
- 工程项目报价模板
- 深色商务模板

**保存后：**

```text
生成报价单
  ↓
进入报价详情
```

### 10. 报价 PDF 预览

**入口：**

```text
报价详情
  ↓
报价 PDF 预览
```

**销售检查：**

- 企业信息、客户信息、产品明细、金额、税率
- 交付条款、付款条款、印章和签字区

**确认无误后：**

- 下载 PDF，或发送给客户

### 11. 发送报价给客户

**入口：**

```text
报价详情
  ↓
发送报价
```

**填写：**

- 客户邮箱、邮件标题、邮件正文
- 是否附带 PDF、是否生成客户在线报价页

**发送后：**

```text
报价状态变为已发送
  ↓
系统生成报价后跟进任务
  ↓
客户可打开在线报价页查看
```

### 12. 客户查看报价

客户收到链接后：

```text
打开客户报价查看页
  ↓
查看报价明细 / 交付条款 / 付款方式
  ↓
联系销售
  ↓
确认报价 / 申请修改
```

**客户操作：**

- 确认报价、申请修改、联系销售、下载附件

### 13. 报价后跟进

**报价发送后系统自动提醒：**

| 条件 | 动作 |
|------|------|
| 报价发送 1 天未回复 | 提醒销售 |
| 报价发送 3 天未回复 | 再次提醒 |
| 报价有效期剩 2 天 | 提醒确认 |
| 客户已查看未回复 | 标记高优先级 |

**销售进入：**

```text
跟进任务
  ↓
报价后跟进任务
```

然后：联系客户 → 添加跟进记录 → 客户确认 / 拒绝 / 要求修改

### 14. 标记成交

**入口：**

```text
报价详情
  ↓
更多操作
  ↓
标记成交
```

**填写：**

- 成交金额、成交日期、成交产品 / 方案
- 付款方式、成交备注
- 是否同步更新客户阶段

**确认后：**

- 报价状态 → 已成交
- 询盘状态 → 已成交
- 客户阶段 → 成交客户
- 首页和数据中心更新成交数据

### 15. 标记丢单

**入口：**

```text
报价详情 / 询盘详情
  ↓
标记丢单
```

**丢单原因（示例）：**

- 价格高、交期慢、产品不匹配、客户预算不足
- 竞品拿下、项目暂停、销售跟进不及时
- 资质不满足、客户无真实需求

**确认后：**

- 报价 / 询盘状态 → 已丢单
- 丢单原因进入数据统计

## 五、老板使用流程

老板不需要配置系统，主要看结果。

### 1. 老板登录

```text
登录系统
  ↓
进入老板首页
```

控制台入口：`/login` → `/dashboard/boss`

**老板首页看：**

- 今日新询盘、有效询盘、待跟进客户
- 逾期未跟进、待报价客户、报价后未回复
- 今日 / 本月成交金额、销售排行、渠道来源统计

### 2. 查看销售是否跟进

**入口：**

```text
首页
  ↓
待处理提醒 / 销售排行
```

**老板重点看：**

- 哪些客户没人跟、哪些任务逾期、哪些报价没人追
- 哪个销售转化率高、哪个销售跟进慢

### 3. 查看询盘和报价

**入口：**

```text
客户机会 → 询盘中心
报价管理
```

**老板可以：**

- 查看全部询盘 / 报价、负责人、客户来源、跟进记录
- 分配负责人、查看成交 / 丢单

### 4. 查看数据中心

**入口：**

```text
数据中心
```

控制台入口：**数据中心**（成交漏斗、渠道分析、销售跟进分析、报表导出）

**V1 重点看：**

- 渠道分析、销售跟进分析、丢单原因分析、报表导出

**老板用这些数据判断：**

- 哪个渠道有效、哪个销售跟得好
- 客户为什么没成交、本月询盘和成交情况

## 六、客户使用流程

客户不登录企业后台，只访问公开页面。

### 1. 客户通过销售链接进入

```text
客户点击销售发来的链接
  ↓
进入 AI 选型页
  ↓
选择产品 → 填写需求 → 上传图纸 → 留下联系方式
  ↓
提交报价需求 → 看到提交成功页
```

**系统后台：**

```text
生成询盘
  ↓
归属对应销售
  ↓
销售收到提醒
```

### 2. 客户通过官网 Widget 咨询

```text
客户访问官网
  ↓
点击右下角 AI Widget
  ↓
咨询产品问题 → AI 回答
  ↓
引导填写需求 / 留联系方式
  ↓
```

## 八、数据隔离流程

系统必须支持多企业。

### 1. 每个企业一个企业空间

示例：

- 企业 A：库滋玛电器
- 企业 B：某某机械厂
- 企业 C：某某智能装备公司

**每个企业的数据独立：**

成员、询盘、报价、客户、知识库、AI 助手、销售链接、AI 选型页、Widget、文件、操作日志

### 2. 登录后绑定企业空间

用户登录后，系统识别：`user_id`、`tenant_id`、`role`、`data_scope`

**所有业务查询都必须带：**

```text
tenant_id = 当前企业
```

### 3. 销售只能看自己的数据

**销售查询条件自动追加：**

```text
tenant_id = 当前企业
owner_id = 当前销售
```

**老板 / 管理员查询：**

```text
tenant_id = 当前企业
```

### 4. 公开链接也要隔离

客户通过公开链接访问时：

```text
salesLinkId / slug / quoteToken / siteKey
  ↓
系统反查 tenant_id
  ↓
只能写入对应企业
```

**不能出现：**

- 客户 A 提交到了企业 B
- 企业 A 读取企业 B 的知识库
- 企业 A 看到企业 B 的报价
