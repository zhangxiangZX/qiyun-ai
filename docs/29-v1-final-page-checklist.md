# 企云图 AI V1 最终验收清单

最后更新：2026-07-10

## 使用方式

这份清单用于最终逐页打勾验收。

建议按顺序执行：

1. 先验公共入口
2. 再验三类角色首页
3. 再验获客入口与 AI 能力
4. 再验询盘、跟进、报价
5. 最后验数据中心与系统设置

验收基线见：

- `docs/28-v1-acceptance-matrix.md`
