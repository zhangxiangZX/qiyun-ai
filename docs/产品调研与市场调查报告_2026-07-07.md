## 二、市场调查

### 2.1 市场规模与增长

| 口径 | 数据 | 来源 / 日期 |
|---|---|---|
| 全球对话式 AI | 2025 **$14.79B** → 2026 $17.97B → 2034 **$82.46B**（CAGR ~21%） | Fortune Business Insights，2026-06-15 |
| 全球对话式 AI（另一口径） | 2025 $14.6B → 2033 $63.2B（CAGR ~20.1%） | Pheonix Research，2025-11 |
| 全球对话式 AI（第三口径） | 2025 $14.62B → 2035 $96.14B | Emergen Research，2026-06-11 |
| 中国智能客服 | 2022 年 66.8 亿 → 2027 年预计 181.3 亿 | 行业研报，2025-04 |
| 中国智能客服（艾瑞口径） | 2022 年 **138 亿 → 2024 年 217 亿** | 艾瑞咨询，2025-12 |
| 全球智能客服（IDC） | 2026 年预计 **$680 亿**，大模型渗透率 **78%** | IDC 引用，2026-06 |

**判断**：无论取哪个口径，赛道都处于 **20%+ CAGR 的高增长区间**，且 2025–2026 是大模型渗透率陡增的拐点年。中国市场的绝对规模（200 亿+ RMB）足够支撑多家垂直厂商。

### 2.2 核心趋势（2025–2026）

1. **AI Agent 主动服务**：从被动关键词应答 → 多轮对话 + 主动触达（如识别高意向访客主动发问、夜间留资）。
2. **全链路留资转化**：客服不再只是"答疑问"，而是"对话即增长"——秒级响应、智能识别意向、人机协同、合规风控、夜间留资五大维度成为标配（2026-04 实测对比）。
3. **人机协同（Copilot）**：AI 处理常规，复杂/高价值转人工；"人工接管"是必备能力而非加分项。
4. **多模态 Agent**：图文 / 语音 / 文件理解进入客服场景。
5. **从成本中心 → 增长引擎**：客服数据反哺营销、销售跟进（这正是 qiyun"销售跟进"模块的战略价值）。

## 三、产品调研（内部）

### 3.1 产品定位（基于代码与既有设计）

**qiyun（齐云）= 面向 B2B 企业的"AI 网站客服 + 智能留资 + 销售跟进"一体化 SaaS。**
核心叙事：**把网站访客对话直接变成可跟进的销售线索，并闭环到报价/客户/跟进**，而非只做"回答问题"。

技术骨架（已验证健康）：
- `apps/console`（Next.js BFF）代理到 `apps/api`（NestJS `qiyun-api`）
- Widget 通过 `<script>` + Shadow DOM 嵌入第三方站点；3 个真实公共 API：`/public/widget/config`、`/public/chat/stream`、`/public/leads`
- Memory / Preview 双模式（预览种子数据 `owner@qiyun.ai / Qiyun@2026`）

### 3.3 优势（Strengths）
- **闭环架构唯一性**：对话 → 线索 → 询盘 → 报价 → 客户 → 跟进，纯客服厂商（美洽/七鱼）不做后半段，纯 CRM 不做前半段。这是 qiyun 最大的结构性差异。
- **Widget 嵌入模型干净**：Shadow DOM 隔离 + script 标签，工程实现优于多数自研。
- **前后台解耦清晰**：BFF 代理 + 公共 API 三件套，扩展性好。
- **设计系统已有基础**：`@qiyun/ui` 组件库（ConfirmDialog/Alert/Sheet 等）可用，迭代底座在。

### 3.4 短板（Weaknesses，来自审计报告）
- **DEMO 假数据以假乱真（P0）**：`sites(DEMO_SITES)`、`quote-detail(DEMO_PRODUCTS)`、`repurchase`、`customer-ops`、`conversation-test`、`channels`、`reports` 等多处"空 → 回退假数据"，真实客户会看到别人家的示例。
- **占位页 / 死按钮 / 死导航（P0）**：已下架 `reports/follow-up`、`lost-reasons`、`export` 三处"V2 开发中"占位；`/dashboard/invitations` 已挂导航；企业资料封面死按钮已修。
- **设计令牌不统一（P0，已修）**：`v2-prototype.css` 把 `--primary` 重定义为 `#3f5eff` 而非设计系统 `#1266ff`——已统一；侧栏/画布过度动效已收敛。
- **客户详情 9 个空 Tab**：空 Tab 比没有更糟，建议"有数据才显示"。
- **通知中心 502（preview 限制）**：`/api/notifications` 在预览模式无上游端点，需降级为空列表。
- **缺少独立工单模块**：对标标杆普遍具备。

## 四、机会与定位建议

1. **抢 Drift 关停窗口**：Drift 的"对话式获客 / 线索 qualifying"客群正在迁移。qiyun 应把"网站对话 → 自动识别意向 → 留资 → 分配销售跟进"做成**第一卖点**，文案直接对位"对话即增长"。
2. **放大闭环唯一性**：在首页/落地页用一条可视化漏斗（对话→线索→询盘→报价→成交）讲清"别人只做客服，我们做增长"。
3. **垂直行业模板**：美洽/快商通靠行业（医美/教育/家装/汽车）起量。qiyun 可先打 1–2 个垂直行业的知识库+话术+留资表单模板。
4. **数据真实化是前提**：所有对外 demo/试用必须先解决"假数据以假乱真"，否则标杆客户一眼识破。
5. **补工单短板**：用最小成本接"会话→工单→跟进"，闭合客服闭环。
