# PRD：对话式获客（Conversational Lead-Gen）

> 版本：v1.0｜日期：2026-07-07｜作者：产品（基于市场调研 + 竞品拆解）
> 配套：`docs/产品调研与市场调查报告_2026-07-07.md`、`docs/竞品逐页拆解_美洽_Intercom_2026-07-07.md`
> 一句话定位：**AI 把网站流量自动变成可跟进的销售线索，并闭环到报价/客户/跟进**——抓 Drift 关停窗口，用"客服+获客+销售跟进"闭环差异化。

---

## 1. 背景与机会

- **市场窗口**：对话式营销标杆 **Drift 于 2026-03-05 宣布 sunset**，其"对话式获客/线索 qualifying"客群正在外溢（来源：Drift sunset 报道 2026-02~06）。纯聊天机器人赛道被整合，方向是"客服+获客+销售跟进"闭环。
- **竞品印证**：美洽靠"大模型获客机器人+套电+新媒体私信"做到 **40% 获线率**居国内首；Intercom（Fin）靠"AI Agent + 按解决效果计费"被 Salesforce 以 **$3.6B** 收购。两者共同证明：**获客留资有强付费意愿 + AI Agent 按效果计费是资本方向**。
- **qiyun 的差异化护城河**：现有"对话→线索→询盘→报价→客户→跟进"闭环是纯客服厂商（美洽/七鱼）不做后半段、纯 CRM 不做前半段的结构性优势。本 PRD 把这条闭环做成**第一卖点**。

## 2. 目标

| 类型 | 目标 |
|---|---|
| 业务目标 | 抓住 Drift 退场流量，把"网站访客→AI 留资→销售跟进"做成可量化增长链路；6 个月内将"有效线索/会话"作为核心计费与增长指标。 |
| 用户目标 | 市场/销售负责人无需开发即可在官网挂一个 AI 获客助手，自动识别高意向访客、引导留资、派发销售并跟踪转化。 |
| 成功指标（见 §7） | 留资率、有效线索量、线索→报价转化率、销售跟进 SLA 达成率、按效果计费 ARPU。 |

## 3. 用户与场景

- **主用户**：B2B 企业的市场/增长负责人、销售运营。
- **终端**：官网访客（匿名→留资）、销售（接收派发的线索并跟进）。
- **典型场景**：
  1. 访客在官网咨询产品 → AI 多轮追问识别意向与预算 → 引导留资（姓名/电话/需求） → 生成线索。
  2. 高意向线索自动派发给对应销售，触发 SLA 计时。
  3. 销售在"客户/跟进"模块看到待跟进线索，超时未跟进系统预警。
  4. 线索进入报价→成交，渠道 ROI 反哺投放。

## 4. 功能范围（MVP → v1.5）

### P0（MVP，本 PRD 核心）
1. **AI 留资 Agent**（招牌能力）
   - 多轮对话意图识别 + 灵活追问，主动引导留资（对标美洽"套电/获客机器人"）。
   - 自动生成"留资卡"（姓名/电话/公司/需求/渠道来源），合规收资。
   - 线索质量评分（高/中/低意向），标注可跟进优先级。
2. **线索自动派发**：留资后按规则（渠道/地区/产品）派发销售，写入"客户/跟进"模块。
3. **跟进 SLA 与预警**：分配后启动 SLA 计时；超时未跟进在通知中心预警（依赖通知降级修复）。
4. **渠道来源追踪**：留资自动带渠道来源（官网 Widget / 抖音 / 微信…），进入渠道转化报表。

### P1（v1.5）
5. **全渠道接入做实**：官网 Widget（已可用）+ 微信/抖音/小红书 新媒体私信接入配置（去"V2 占位"）。
6. **按效果计费后台**：AI 有效留资/有效会话按量计费（对标 Fin $0.99/resolution；建议 ¥0.5–1/条有效线索），含用量报表。
7. **会话转工单**：高复杂对话一键转工单并跟踪（补工单模块短板）。
8. **数据分析反哺投放**：客服/留资数据 → 渠道 ROI 看板，强化 CMO 视角。

### P2（远期）
9. AI 语音客服（对标美洽降 80% 人工）。
10. 开放 API / CRM 双向同步（为被大平台集成留接口）。

## 5. 数据流（闭环）

```
官网 Widget / 新媒体私信
   │  (对话流 SSE)
   ▼
[AI 留资 Agent] ──意图识别+追问──▶ [留资卡]
   │                                    │
   │                                    ▼
   │                              [线索 Leads] (质量评分/渠道来源)
   │                                    │ 自动派发规则
   │                                    ▼
   │                              [销售跟进 SLA] ──超时──▶ [通知预警]
   │                                    │
   │                                    ▼
   └─────── 同一对话上下文 ──────▶ [询盘 → 报价 → 客户 → 成交]
                                          │
                                          ▼
                                    [渠道 ROI 报表] ──反哺投放
```

- 关键：留资 Agent 与"会话/线索/客户"共用同一 `botId`/`siteKey` 上下文，避免信息孤岛（现有 `public/chat/stream`、`public/leads` 公共 API 已具备基础）。

## 6. 关键用户故事

- **US-1**（市场）作为市场负责人，我希望在官网挂一个 AI 获客助手且不用写代码，以便快速上线获客入口。
- **US-2**（AI）作为访客，我希望被自然追问而非机械表单，以便顺畅留下需求。
- **US-3**（销售）作为销售，我希望高意向线索自动派给我并带上下文，以便跟进不丢上下文。
- **US-4**（管理者）作为销售管理者，我希望看到超时未跟进预警与渠道 ROI，以便管理团队与投放。

## 7. 成功指标（North Star + Guardrails）

| 指标 | 定义 | 目标（6 个月） |
|---|---|---|
| 留资率 | 留资访客 / 对话访客 | ≥ 25%（对标美洽近 40%） |
| 有效线索量 | 评分≥中的线索数 | 月环比 +30% |
| 线索→报价转化率 | 进入报价的线索占比 | ≥ 35% |
| 跟进 SLA 达成率 | 超时前首触达占比 | ≥ 90% |
| 按效果计费 ARPU | 有效线索 × 单价 | 验证定价模型 |

## 8. 范围边界（Out of Scope）

- 不重做纯售后工单系统（仅会话转工单最小闭环）。
- 不绑定单一大模型（支持多模型接入，保持 RAG 知识库中性）。
- v1 不做 AI 语音（P2）。

## 9. 优先级与里程碑

| 里程碑 | 内容 | 依赖 |
|---|---|---|
| M1（2 周） | AI 留资 Agent + 留资卡 + 质量评分（前端+API 公共接口） | public/leads 已具备 |
| M2（2 周） | 线索自动派发 + 跟进 SLA + 通知预警 | 通知降级修复（见 P1 代码） |
| M3（3 周） | 全渠道接入做实 + 会话转工单 | 渠道配置、工单模块 |
| M4（2 周） | 按效果计费后台 + 渠道 ROI 报表 | 用量计量、报表 API |
