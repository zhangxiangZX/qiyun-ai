## 待评估 IDEA（2026-07-08 新增）

> 来源：用户反馈「项目里很多功能没实现：日历 / 地图 / 文档下载上传(加水印) / 二维码生成」。
> 判定：均不在 MVP 清单 A–I，且不增强获客闭环 → 按护栏归 V2 候选，禁止直接纳入 V1.0 开发。

### [IDEA-001] 日历 / 日程视图
- **来源**：用户反馈
- **想解决的问题**：后台提供日历视图，查看销售跟进日程、演示安排等
- **与核心闭环的关系**：无直接关系（跟进当前用「状态 + 文字跟进记录」实现，闭环已闭环）
- **预计优先级**：P2 / 暂不评估
- **不做原因**：不在 MVP 清单 A–I；不增强获客闭环；属 V2 候选

### [IDEA-002] 地图 / 地理位置
- **来源**：用户反馈
- **想解决的问题**：客户 / 线索地域分布、就近服务网点展示
- **与核心闭环的关系**：无直接关系
- **预计优先级**：P2 / 暂不评估
- **不做原因**：不在 MVP 清单；需引入地图 SDK（高德 / 腾讯 / Mapbox）与外部密钥，超出 V1.0 边界

### [IDEA-003] 文件下载 / 上传 + 水印
- **来源**：用户反馈
- **想解决的问题**：知识库 / 线索附件导出时加防伪水印；更丰富的文档预览
- **与核心闭环的关系**：弱相关（基础上传 B-03 / E-04 已在 V1.0 实装；下载加水印不在 V1.0）
- **预计优先级**：P2
- **不做原因**：基础上传已覆盖；下载加水印需后端 + 水印库（pdf-lib / sharp），属 V2 增强

### [IDEA-004] 二维码生成
- **来源**：用户反馈
- **想解决的问题**：为 Site Key / 安装代码 / 会话分享生成二维码，便于移动端扫码
- **与核心闭环的关系**：弱相关（可增强 D-11 安装代码分享体验）
- **预计优先级**：P2（体量最小、自包含，可作为 V2 轻量增强优先做）
- **不做原因**：不在 MVP 清单；但实现成本低，适合作为 V2 第一个落地项
