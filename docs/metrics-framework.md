# 指标体系设计（Metrics Framework）

> 目的：让"功能好不好用、闭环通不通"从体感变成可衡量数字。
> 适用：企云 AI 控制台（智能客服 + 知识库 + 线索管理）
> 作者：产品通 ｜ 日期：2026-07-08

---

## 1. 北极星指标（North Star）

**有效留资转化率（Qualified Lead Conversion Rate）**

```
北极星 = 周期内 AI 对话引导产生的「有效留资」数 / 周期内 AI 对话总数
```

- **为什么是它**：产品核心价值是把"访客咨询"变成"可跟进的销售线索"。它同时驱动「对话质量（知识库命中）」「业务规则约束（何时转人工/收资）」「留资表单体验」三条链路，且直接对齐营收。
- **基线**：当前无法统计（上游接口大面积 500/404，详见 `product-audit-2026-07-08.md`）。需先打通后端才能采集。
- **目标**：首月 ≥ 25%，3 个月 ≥ 35%。

> 备选北极星：若短期更关注"AI 替代人工"，可用「AI 自助解决率」（无需转人工的会话占比）。建议二者同看，北极星取留资转化。

---

## 2. 驱动指标（Drivers）—— 拆开北极星的杠杆

| 驱动指标 | 定义 | 基线 | 目标 | 关联功能 |
|----------|------|------|------|----------|
| 对话命中知识库率 | 含知识库引用的会话 / 总会话 | 未知 | ≥ 70% | 知识库、对话测试 |
| 业务规则触发率 | 触发至少 1 条业务规则的会话 / 总会话 | 未知 | ≥ 40% | 业务规则 |
| 留资表单完成率 | 提交留资 / 进入留资表单 | 未知 | ≥ 60% | 对话测试、Widget |
| 跟进任务完成率 | 按时完成的跟进 / 到期跟进 | 未知 | ≥ 80% | 跟进任务、日历 |
| 询盘→报价转化率 | 生成报价的询盘 / 总询盘 | 未知 | ≥ 30% | 询盘、报价 |
| 报价→成交率 | 成交报价 / 总报价 | 未知 | ≥ 20% | 报价、CRM |

> 驱动指标当前**全部无基线**——因为询盘/报价/CRM 后端接口处于 500/404（见审计 D1/D2）。打通后端是采集前提。

## 3. 健康指标（Health）—— 系统能不能"正常运转"

| 健康指标 | 定义 | 警戒线 | 关联缺陷 |
|----------|------|--------|----------|
| 页面加载成功率 | 关键页 2xx 占比 | < 99% 告警 | D1/D2（10 路由异常） |
| API 5xx 率 | 后端 500 占比 | > 0.1% 告警 | D2（4 路由 500） |
| API 404 率（已注册路由） | 预期内不应 404 | > 0 即异常 | D1（6 路由 404） |
| 401 占比 | 鉴权失败占比（含过期） | 突增即异常 | D5（无重登引导） |
| 页面切换感知耗时 | 切页到可见时间 | > 0.8s 告警 | D7（动画 0.5s 已修） |
| 二进制下载完好率 | 图片/PDF 下载未损坏占比 | < 100% 告警 | 已修（proxy arrayBuffer） |

---

## 4. 指标落地建议

1. **先通后量**：当前 10 个路由异常，指标连采集都做不到。优先级 = 先修 D1+D2（审计文档），再接入埋点。
2. **埋点位置**：前端在 `apiRequest` 统一拦截（成功/失败/耗时），后端在 `ApiResult` 出口统一计数——避免各页面散点埋点。
3. **看板承载**：数据中心「机器人洞察 /reports/bot-insights」天然是载体；但 `/reports` 当前 401（需鉴权），先保证登录态透传稳定。
4. **告警而非报表**：健康指标设阈值告警（如 5xx 率 > 0.1% 自动通知），比月度报表更能防"加载不出来"类事故。

| 文档 | 回答的问题 |
