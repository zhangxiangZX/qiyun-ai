# 企云图 AI 商业候选版交付清单

更新日期：2026-07-22

## 当前结论

当前代码达到商业候选版（Release Candidate）标准，可以进入部署后的生产验收。正式对客户开放前，必须完成本文件中的生产环境检查。

## 已完成

- 真实模式不再用演示数据静默兜底，接口失败会显示错误或空状态。
- Owner、管理员、销售角色首页和访问边界通过自动化测试。
- AI 选型页发布、预览、渠道链接和客户入口使用同一真实 slug。
- 生产公开链接优先使用 `NEXT_PUBLIC_ENTRY_URL`，对应 `go.qiyuntu.cn`。
- 未发布页面不生成可对外传播的渠道链接。
- 公开选型表单校验全部必填字段、电话、邮箱和隐私同意。
- 试用申请统一使用“企云图 AI”品牌并增加协议与隐私确认。
- 报价状态、日期和搜索筛选真实生效；重置会清空全部条件。
- 乱码客户、产品和负责人名称有安全降级展示。
- 正式模式不再显示 API/BFF 等开发术语。
- 未上线的全局搜索和帮助入口已隐藏。
- 报价 KPI 卡片完成常见桌面宽度适配。

## 正式发布判定

只有当以上生产检查全部完成，并且真实业务闭环“客户提交 -> 询盘 -> 分配 -> 跟进 -> 报价 -> 客户查看 -> 成交”无 P0/P1 缺陷时，才能标记为正式商业版本。
