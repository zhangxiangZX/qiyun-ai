### 1.3 落地页话术（原话/主题）
- 主标语：**「每一次对话，都是一次增长」**；副标「让更多企业轻松拥有客服 AI」。
- 句式："AI 大模型 + 多渠道数据融合，实现**对话即增长**"；"如同一位 7×24 小时在线的专业售前经理，灵活追问引导留资"；"独立解决 90% 以上常见问题 / 降低 80% 人工坐席"；"升级大模型机器人 1 个月，获线率近 40%"。

### 1.4 定位与客群
- 规模：小团队→中小→大型；行业：教育、医疗、电商、金融。
- 主打场景：**获客转化 + 私域沉淀 + 新媒体渠道客资增长**，非纯售后。定位"AI 驱动的智能获客平台 / 一站式客服营销一体化"。

## 三、行业整合信号（对标关键）
- **Drift 关停（2026）**：对话式营销标杆 Drift 被 Clari+Salesloft 收购后于 **2026-03-05 sunset**，客户导向 1mind 等继任者 → "纯对话式营销/聊天机器人"赛道被整合，**"客服+获客+销售跟进"闭环才是去向**。
- **整合潮**：Salesforce→Fin($3.6B)、Clari+Salesloft→Drift 退场，AI 客服向"Agent + 大平台"集中，独立厂商要么被并购要么做深垂直闭环。

## 四、反推 qiyun 的定价与卖点

### 4.1 定价策略（三角定位）
| 对标 | 建议档位 | 锚点 | 计费 |
|---|---|---|---|
| 美洽体验版 | **免费版** | ¥0 | 限坐席/月线索数 |
| 美洽专业 + Intercom Essential | **成长版** | ¥1,500–2,000/坐席/年 或 $29/坐席/月 | 坐席+年付 |
| 美洽企业 + Intercom Advanced | **商业版** | ¥3,500–4,500/坐席/年 或 $85/坐席/月 | 坐席+模块 |
| Intercom Expert/旗舰 | **企业版** | 询价/定制 | +私有化/API/安全 |
| **差异化（学 Fin）** | **AI 留资按效果计费** | **¥0.5–1/条有效线索** 或 含包量 | 用量费 |

- **核心建议**：不只卖坐席。引入 **"AI 有效留资/有效会话"按量计费**（对标 Fin $0.99/resolution），让小客户低门槛进入、大客户按效果放大——这是美洽（纯坐席）与 Intercom（坐席+解决）的中间最优点。
- 设**免费版**（限坐席/月线索数）做获客漏斗，学美洽"免费试用"+Intercom 新客折扣。

### 4.2 卖点话术方向
- 学美洽"**对话即增长**"——价值锚定**获客/留资转化**而非"客服降本"（与 Intercom 区隔）。
- 学 Fin"**AI Agent 时代 / 每一次对话都更好**"——强调"网站访客→AI 留资→销售跟进"**闭环自动流转**。
- **推荐主标语**：「**每一次对话，自动留资、自动跟进**」或「**AI 把网站流量变成销售线索**」。
- 关键词：智能留资、自动跟进、线索不流失、销售闭环、7×24 AI 员工。
- **反 Drift 信号**：对外强调"不是又一个聊天机器人，而是获客+CRM+销售跟进的闭环"，规避"纯对话式营销"被整合的命运。

### 4.3 该优先补的功能（对标两家）
1. **招牌 AI 留资 Agent**（最高优先）：多轮追问引导留资 + 自动发"留资卡" + 线索质量评分。
2. **销售跟进闭环**：留资后自动派发销售、SLA 提醒、跟进状态看板（qiyun 独有护城河）。
3. **全渠道接入**：网站 Widget + 微信/抖音/小红书 新媒体私信。
4. **按效果计费后台 + 用量报表**。
5. **知识库/RAG + 人机协同**（基础必备）。
6. **开放 API / CRM 双向同步**（为被大平台集成/并购留接口）。
7. **数据分析反哺投放**（强化 CMO 视角买单）。

> **一句话结论**：美洽证明"国内获客留资"有强付费意愿且按坐席可跑通；Fin 证明"AI Agent 按解决效果计费 + 大平台整合"是资本方向；qiyun 应走 **"美洽的获客留资叙事 × Fin 的效果计费 × 独有的销售跟进闭环"** 三角定位，以免费版做漏斗、以有效线索按量收费做放大。
