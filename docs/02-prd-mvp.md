# 02 PRD｜MVP 产品需求说明书

## 1. 用户角色
| 角色 | 权限 |
|---|---|
| Owner | 工作区全部权限、成员管理、删除工作区 |
| Admin | 管理机器人、知识库、会话、线索、站点 |
| Operator | 查看会话、处理线索、维护知识库 |
| Viewer | 只读数据看板与会话 |

## 2. 核心用户流程
### 2.1 首次开通
注册 → 创建工作区 → 新建机器人 → 上传资料 → 等待索引完成 → 配置站点 → 复制嵌入代码 → 在官网部署 → 测试会话。

### 2.2 访客咨询
访客打开官网 → Widget 初始化 → 新建匿名会话 → 提问 → 服务端检索知识库 → LLM 基于上下文流式回答 → 显示来源 → 无答案/用户触发时展示留资表单 → 创建线索。

## 3. 功能需求

### F-01 认证与工作区
- 支持邮箱 + 密码登录；V1 可不做短信/第三方登录。
- 一个用户可属于多个工作区。
- 新用户必须创建或加入工作区后才能进入控制台。
- 工作区所有业务数据必须带 `workspace_id`，服务端强制隔离。

验收：
- 用户 A 无法读取或修改用户 B 工作区任意资源。
- Owner 可邀请、移除成员，Admin 不能删除 Owner。

### F-02 知识库
- 支持 `.pdf`、`.docx`、`.txt`、`.md`，单文件最大 20MB。
- 上传后状态：`uploaded → parsing → indexing → ready | failed`。
- 文件解析成文档、分块、向量；失败记录可读错误信息。
- 支持按知识库启用/停用、删除文件、重新索引。
- 每一个回答最多引用 3 个来源片段。

验收：
- 已索引文件可被机器人检索。
- 停用知识库后，该知识库内容不再进入模型上下文。
- 删除文档后，向量检索中无残留。

### F-03 机器人
字段：
- 名称、头像、欢迎语、系统提示词、默认模型
- 关联知识库（多选）
- 温度（0–1）、单轮最大输出 token
- “无法回答时收集线索”开关
- 留资表单字段配置（姓名、电话、邮箱、公司、问题）

行为：
- 默认系统提示词必须要求“只根据知识库回答；信息不足时明确说明并引导人工联系；不得编造”。
- 机器人状态：draft / active / disabled。

### F-04 Web Chat Widget
- 提供 `<script>` 嵌入代码。
- 初始化参数：`botId`、`siteKey`、可选主题色/语言。
- 仅允许在站点白名单域名运行。
- 支持匿名访客 ID、本地会话恢复、流式消息、重新生成、来源展示。
- Widget 必须移动端适配，不能破坏宿主页面 CSS。

验收：
- 在已白名单域名可正常对话。
- 在非白名单域名返回 403。
- 首 token 目标 < 5 秒（不含模型供应商异常）。

### F-05 会话与线索
- 控制台可筛选会话：时间、机器人、是否已留资、是否未解决。
- 会话详情显示消息、引用、模型、token、耗时。
- 留资后生成线索；可标记新建/跟进中/已成交/无效，支持备注。
- CSV 导出线索。

### F-06 数据看板
卡片：
- 今日会话数
- 今日访客数
- 今日线索数
- 平均响应时间
- 未解决问题数

图表：
- 最近 7/30 天会话趋势
- 线索趋势
- 高频问题（按相似问题聚类，V1 可按关键词简化）
- 未命中问题列表

## 4. 非功能要求
- 响应式：控制台支持 1280px 桌面与 375px 手机。
- 安全：鉴权、工作区隔离、文件类型与大小校验、速率限制、审计日志。
- 可观测：请求 ID、错误日志、任务失败可追踪。
- 性能：控制台常规接口 P95 < 800ms；Widget 首 token < 5s；聊天接口支持 SSE。
- 容量：上线前必须完成压测，记录单节点可支撑的活跃会话数、API QPS、知识库文档量上限与扩容阈值。
- 可用性：API 与 Worker 保持无状态，异步任务必须可重试、幂等、可追踪。
- 数据保护：原始文件与对象存储私有化；数据库每日备份；关键操作写审计日志。
- 可访问性：键盘可操作，表单有标签，颜色对比符合 WCAG AA 基本要求。
