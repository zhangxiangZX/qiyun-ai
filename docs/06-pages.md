# 06 页面说明与交互

## P-01 登录 / 注册
- 极简双栏布局：左侧价值主张，右侧表单。
- 注册成功后进入“创建工作区”。
- 表单必须有 loading、错误提示、密码显示切换。

## P-02 Dashboard
顶部：工作区切换、通知、用户菜单。  
主体：
1. 4 个 KPI 卡片
2. 7/30 天趋势图
3. 高频问题 / 未解决问题双栏
4. 最近线索表格

空状态：引导“创建第一个机器人”。

## P-03 机器人列表与编辑
- 列表：名称、状态、关联知识库数、近 7 天会话、更新时间。
- 编辑使用左侧二级导航：
  - 基础设置
  - 知识库
  - 行为与安全
  - 留资表单
  - 安装代码
- 右侧永远显示可交互的 Chat 预览面板。

## P-04 知识库
- 顶部：新建知识库、上传文件。
- 文件列表：文件名、类型、大小、状态、切分数、更新时间、操作。
- 状态应有清晰图标和文字，失败可查看错误与重试。
- 上传区域支持拖拽，但不能仅依赖拖拽。

## P-05 会话
- 左：会话列表（访客、摘要、时间、状态）。
- 中：聊天消息流和引用。
- 右：会话属性、留资信息、标签、处理状态。
- 移动端改为抽屉式切换，不强塞三栏。

## P-06 线索
- 表格：姓名、联系方式、来源机器人、最近问题、状态、负责人、创建时间。
- 支持筛选、搜索、状态更新、备注、CSV 导出。

## P-07 站点与嵌入
- 显示站点域名白名单。
- 展示一键复制 script 代码。
- 提供“发送测试消息”校验卡。
- 明确提示：更换域名后需保存，非白名单会被拒绝。

## 交互原则
- 每个异步操作都必须有 loading、成功反馈、失败反馈、可重试机制。
- 删除必须二次确认，说明影响范围。
- 不用“仅图标”承载关键操作；危险操作使用文字确认。
