# AI云 · 第一版全部功能可用清单（MVP 交付版 V1.0）

> 目标：让 AI云具备“可给工业设备客户演示、可接入一个真实官网、可产生线索、可后台跟进”的完整闭环。  
> 本清单是 V1.0 的唯一开发边界。  
> 未列出的功能一律不进入第一版开发，放入 `docs/BACKLOG.md`。

---

# 0. 第一版完成定义

第一版不是“页面都做完”，而是以下真实业务链路可跑通：

```text
平台管理员创建工业客户工作区
→ 邀请客户企业管理员
→ 客户登录后台
→ 上传产品 PDF / Word / FAQ / 参数资料
→ Worker 完成解析、切片、向量索引
→ 客户配置官网机器人
→ 获取 Site Key / 安装代码
→ 在客户官网嵌入 Widget
→ 访客提问
→ AI 基于客户知识库回答并展示来源
→ 报价 / 图纸 / 非标 / 交期 / 定制等需求触发留资
→ 线索进入后台
→ 销售查看会话、需求摘要、联系方式、附件
→ 销售更新跟进状态
→ 管理员查看未解决问题和基础数据
```
