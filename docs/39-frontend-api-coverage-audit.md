# 前端功能与后端接口覆盖审计

审计范围：V1 工作台、企业与账号、获客入口、AI 能力中心、客户机会、销售跟进、报价、数据中心和系统设置。

## 已有正式接口

- 登录、验证码、注册、找回密码、工作区切换、成员邀请、角色权限和企业资料。
- 角色工作台、询盘列表/详情/分配/补充/转报价/成交/丢单。
- 快速录入 AI 抽取、查重、创建询盘和最近记录。
- 跟进任务、跟进记录、日历事件和自动首次跟进。
- 报价 CRUD、模板、PDF、公开查看、发送、交付日志和重试。
- 知识库、文档上传/解析/重试/删除、RAG 检索和聊天 SSE。
- AI 选型页、公开提交、附件继承和提交转询盘。
- 销售链接 CRUD、公开跳转、扫码日志和转化统计。
- 站点、site key、安装检测、Widget 配置和测试消息。
- Dashboard、渠道、漏斗、丢单、销售跟进、地域和报表导出。
- 通知、操作日志、系统状态和平台试用审核。

## 本轮修正

- 页面统一使用 `ConsolePage` 画布，收口最大宽度、响应式边距和纵向节奏。
- `PageHeader` 改用设计 token 的 H1/正文规格，避免页面各自定义字号。
- 清理 Calendar、Geo、Sites 中已经失效的“后端未实现”提示。
- Widget 脚本 CDN 与聊天 API 拆分，嵌入代码同时输出 `src` 和 `data-api-base`。
- 销售链接公开地址统一到 `go.qiyuntu.cn`。

## 非接口缺口

- Preview 模式的 mock 是无上游环境的演示降级，不代表生产接口缺失。
- 客户运营、复购、售后、账单、支付、复杂权限属于 V2，不纳入 V1 补接口范围。
- 仍需浏览器逐页检查少量独立 CSS Module 页面；共享壳已确保基础栅格一致。
