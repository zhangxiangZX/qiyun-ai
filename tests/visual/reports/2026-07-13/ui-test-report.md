## 问题条目

### 1

页面名称：C-02 询盘中心 / J-01 顶栏  
问题位置：顶栏右上角 · 工作区名称  
截图：`c02-inquiries-1366x768.png`  
问题等级：**P2**  
修改建议：1366 视口下「企云科技有限公司」被截断为「企云科技有限公…」。放宽 `.topbar-tools` 区 min-width 或加 `title` tooltip，保证 SaaS 客户可识别当前租户。

### 2

页面名称：C-02 询盘中心  
问题位置：顶栏 · 页面标题  
截图：`c02-inquiries-1920x1080.png`  
问题等级：**P2**  
修改建议：顶栏 H1 实测 **20px / 700**，与规范「页面标题 ~24px / 600」及 `docs/07` H1 层级略有偏差。统一为 design token（如 `--fs-h1`）并在全站顶栏对齐。

### 3

页面名称：C-02 询盘中心  
问题位置：内容区顶部 · 绿色横幅  
截图：`c02-inquiries-1920x1080.png`  
问题等级：**P2**  
修改建议：展示开发向文案「Connected to upstream API (apps/api) via BFF proxy」。正式环境应隐藏或改为用户可读「数据已同步」；避免客户试用时暴露内部架构。

### 4

页面名称：C-02 询盘中心  
问题位置：整页 · 面包屑  
截图：`c02-inquiries-1920x1080.png`  
问题等级：**P2**  
修改建议：`docs/40` 要求面包屑；当前仅顶栏扁平标题「询盘中心」，无「客户机会 › 询盘中心」路径。若 V1 设计稿有层级导航，需补 Breadcrumb 组件。

### 5

页面名称：C-02 询盘中心  
问题位置：表格 · 需求完整度列  
截图：`c02-inquiries-1920x1080.png`  
问题等级：**P1**  
修改建议：列表多行「需求完整度」均为 **0%** 空进度条，演示/demo 观感像数据坏掉。Mock 应给出 20–80% 分布，或空态说明「待补充资料」。

### 6

页面名称：C-02 询盘中心  
问题位置：表格 · 产品需求列  
截图：`c02-inquiries-1920x1080.png`  
问题等级：**P2**  
修改建议：`.productType { max-width: 120px }` 导致「户外机柜 20台…」过早省略。建议放宽至 180–220px 或 hover tooltip 展示全文。

### 7

页面名称：C-02 询盘中心  
问题位置：筛选区  
截图：`c02-inquiries-filter-open.png`  
问题等级：**P2**  
修改建议：顶栏已有日期区间按钮，展开后又重复「开始日期/结束日期」；交互冗余。合并为一处日期选择器，或展开后面包屑式展示已选条件。

### 8

页面名称：C-02 询盘中心  
问题位置：筛选面板 / 导出提示 / 快捷图标  
截图：`c02-inquiries-filter-open.png`  
问题等级：**P2**  
修改建议：多处 inline style 硬编码色值（`#e2e8f0`、`#64748b`、`#3b82f6` 等），违反 `docs/07` token 规则。迁移至 CSS module 或 `@qiyun/ui` 变量；「跟进任务」误用 Search 图标，应改为 ListTodo/CheckSquare。

### 9

页面名称：C-02 询盘中心  
问题位置：1440 / 1366 响应式布局  
截图：`c02-inquiries-1440x900.png`、`c02-inquiries-1366x768.png`  
问题等级：**P1**  
修改建议：`max-width: 1400px` 时右侧「待办/快捷/AI」整列下移至表格之后，页面纵向高度 **>2000px**，主操作与辅助面板分离过远。建议 ≤1400 时改为可折叠侧栏或 Sticky 快捷条，避免销售高频操作沉底。

### 10

页面名称：J-01 侧栏  
问题位置：收起状态  
截图：`j01-sidebar-collapsed.png`  
问题等级：**P2**  
修改建议：收起后仅图标，无 hover tooltip / aria-label 朗读子项名称，新用户难以辨认。为 `.sidebar--collapsed` 链接加 Tooltip（Radix）及 `title`。

### 11

页面名称：J-01 侧栏  
问题位置：选中态 · 子菜单「询盘中心」  
截图：`c02-inquiries-1920x1080.png`  
问题等级：**P2**  
修改建议：选中子项为渐变胶囊 + 白字，视觉质量良好；但子项高度 **33px** 与一级 toggle 行高需目测对齐（偶发基线不齐时统一 `min-height: 36px`）。
